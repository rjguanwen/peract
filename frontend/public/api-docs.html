API 文档

躬行（Peract）· Go 后端（Gin）· 基础地址 http://localhost:8001/api/v1

系统说明

本系统后端基于 Go + Gin + GORM + SQLite，提供任务登记、分配、进展跟踪、状态查询、提醒、回收站等功能。

  • 除登录/注册外，所有接口均需 Authorization: Bearer <token> 请求头。
  • 登录接口使用 OAuth2 Password 模式（application/x-www-form-urlencoded）。
  • 错误响应统一格式：{"detail": "错误信息"}。
  • 时间字段格式：2026-08-20T18:00:00（本地时间，无时区）。
  • PATCH 类接口为局部更新：字段缺省或为 null 都表示「本次不改」，清空必须用显式标志（见任务接口）。
  • 登录失败与找回密码等敏感接口有频率限制，超限返回 429 并带 Retry-After 秒数。

认证接口

POST/auth/login
用户登录，返回 JWT 访问令牌。请求体为表单格式（非 JSON）。
参数位置类型必填说明
usernameFormstring是用户名
passwordFormstring是密码

响应 200

{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user": { "id": 1, "username": "admin", ... }
}
同一「来源 IP + 用户名」在窗口内失败次数超过阈值（默认 10 分钟 5 次）后返回 429， 响应头 Retry-After 为待等秒数；锁定期内即使口令正确也会被拒。口令错误与账号不存在返回同一个 400 提示。
POST/auth/register
注册新用户（角色固定为普通用户）。
参数类型必填说明
usernamestring是2-64 位，字母/数字/下划线/点/横线
emailstring是合法邮箱
passwordstring是至少 6 位
full_namestring否姓名
rolestring否忽略，固定为 user
inviteTokenstring否邀请令牌（来自管理员发出的邀请链接）
管理员关闭自助注册后，仅携带有效 inviteToken 的请求能注册成功（否则 403）； 邀请链接与邮箱绑定，一次性、默认 7 天过期。

响应 201

{ "id": 2, "username": "user1", "email": "...", "role": "user", ... }
GET/auth/me 需登录
获取当前登录用户信息。

响应 200

{ "id": 1, "username": "admin", "role": "admin", "is_active": true, ... }
POST/auth/logout 公开
退出登录：把当前访问令牌加入吊销名单，使其立即失效。不携带令牌时为空操作。

响应 200

{ "success": true }
GET/auth/invite/info 公开
校验邀请令牌并返回受邀邮箱与邀请人，供注册页预填。
参数位置类型说明
tokenQuerystring邀请令牌（链接里的 ?invite=）

响应 200

{ "email": "new@example.com", "invitedByDisplayName": "系统管理员", "expiresAt": "2026-08-21 10:00:00" }
令牌无效 / 已过期 / 已被使用 / 已撤销均返回 400，detail 里说明具体原因。

账号与安全

PUT/auth/password 需登录
修改自己的密码。
参数类型必填说明
oldPasswordstring是原密码
newPasswordstring是至少 6 位，且不得与原密码相同

响应 200

{ "success": true }
成功后当前会话与此前签发的全部令牌立即失效（含已泄露的旧令牌），前端必须改走重新登录。
GET/auth/security 需登录
读取自己的安全设置（不返回答案）。

响应 200

{ "password_hint": "...", "security_question": "...", "has_security": true, "answer_legacy": false }
answer_legacy: true 表示存量明文答案，已停止参与校验，需重新设置一次。
PUT/auth/security 需登录
设置/清除密码提示与安全问答（部分更新，只传需改的字段）。
参数类型说明
passwordHintstring密码提示，最多 128 字
securityQuestionstring安全问题
securityAnswerstring答案，最多 128 字，以 bcrypt 哈希入库
只改 securityQuestion 而不带 securityAnswer 会返回 400，避免题目与答案对不上。
PUT/profile 需登录
更新个人资料，响应为更新后的完整用户对象。
参数类型说明
full_namestring昵称/姓名，最多 128 字
signaturestring个性签名，最多 80 字
PUT/profile/avatar 需登录
上传头像（multipart/form-data，字段名 file），替掉旧图时删除旧文件。
参数类型说明
filefile图片，≤ 5MB；类型按文件头魔数判定（png / jpeg / gif / webp）
不信任客户端的 Content-Type 与扩展名；识别不出的内容返回 400。
GET/auth/forgot 公开
按邮箱查找回题目。email 为 Query 参数。

响应 200

{
  "exists": true,
  "security_question": "母校叫什么？",
  "password_hint": "...",
  "has_security": true,
  "answer_legacy": false
}
邮箱不存在与账号已停用返回完全相同的响应（均为 exists: false），不得用于探测邮箱是否注册。 存量明文答案的账号会置 answer_legacy: true 且不再返回题目。
POST/auth/forgot/reset 公开
凭安全问题答案重置密码。
参数类型必填说明
emailstring是注册邮箱
answerstring是答案（比对前去除首尾空白，走哈希比较）
newPasswordstring是新密码，至少 6 位
答案错误与邮箱不存在提示同一句话；超过频率限制返回 429； 存量明文答案返回 423 Locked，需重设安全答案或改用邮件链接。
POST/auth/forgot/send 公开
向注册邮箱发送一次性重置链接（后台队列发信，请求本身不阻塞）。
参数类型必填说明
emailstring是注册邮箱

响应 200

{ "sent": true }
邮箱不存在、已停用与发送成功一律回同样的 {"sent": true}，不供探测。 SMTP 未配置时：生产环境返回 503；非生产环境则返回 {"sent": false, "dev": true, "reset_url": "..."} 便于本地联调。
POST/auth/reset 公开
使用邮件里的重置令牌设置新密码。
参数类型必填说明
tokenstring是重置令牌，有效期 30 分钟且用一次即废
newPasswordstring是新密码
重置后该账号此前签发的全部令牌作废；访问令牌不能当重置令牌用，反之亦然。

任务接口

POST/tasks 需登录
创建任务（登记）。创建后自动在进展时间线记录「created」。
参数类型必填说明
titlestring是任务标题
descriptionstring否任务描述
prioritystring否low / medium / high / urgent，默认 medium
assignee_idinteger否负责人用户 ID
due_datestring否截止时间 2026-08-20T18:00:00

响应 201

{ "id": 10, "title": "...", "status": "todo", "progress": 0, ... }
GET/tasks 需登录
任务列表，支持组合筛选与分页。
参数位置类型说明
statusQuerystringtodo / in_progress / done
priorityQuerystringlow / medium / high / urgent
assignee_idQueryinteger负责人 ID
keywordQuerystring标题/描述模糊搜索
overdue_onlyQueryboolean只看逾期（true）
mineQueryboolean只看我的任务（true）
pageQueryinteger页码，默认 1
page_sizeQueryinteger每页条数，默认 20，最大 100

响应 200

{
  "items": [ { "id": 10, "status": "todo", ... } ],
  "total": 42,
  "page": 1,
  "page_size": 20
}
GET/tasks/deleted 需登录
回收站：已逻辑删除的任务。管理员可见全部；普通用户仅可见自己创建的任务。
参数位置类型说明
priorityQuerystring按优先级筛选
keywordQuerystring标题/描述模糊搜索
page / page_sizeQueryinteger分页参数
响应结构与 GET /tasks 相同；每条记录包含 deleted_at 删除时间。
GET/tasks/:id 需登录
任务详情，包含完整字段与进展时间线 progresses。

响应 200

{
  "id": 10,
  "title": "...",
  "status": "in_progress",
  "progress": 60,
  "is_overdue": false,
  "progresses": [ { "action": "status_changed", ... } ]
}
PATCH/tasks/:id 需登录
更新任务。权限规则： 编辑基本信息（title / description / priority / assignee_id / due_date）仅限管理员或任务创建者； 状态/进度流转（status / progress）允许负责人操作。
参数类型说明
titlestring标题（仅管理员/创建者）
descriptionstring描述（仅管理员/创建者）
prioritystring优先级（仅管理员/创建者）
assignee_idinteger负责人（仅管理员/创建者）
clear_assigneeboolean置 true 清空负责人（仅管理员/创建者）
due_datestring截止时间（仅管理员/创建者）
clear_due_dateboolean置 true 清空截止时间（仅管理员/创建者）
statusstring状态流转（负责人可操作）
progressinteger进度 0-100，达 100 自动完成（负责人可操作）
清空字段必须用 clear_* 标志：本接口是 PATCH 语义，assignee_id 缺省或传 null 都等于「本次不改」，只有 {"clear_assignee": true} 会真的写 NULL。 同一字段与其 clear_* 标志同时出现视为冲突，返回 400。
状态/进度变更会自动记录到进展时间线，并通知负责人。
DELETE/tasks/:id 需登录
仅管理员或任务创建者。逻辑删除：写入 deleted_at，可在回收站恢复。

响应 204

POST/tasks/:id/restore 需登录
仅管理员或任务创建者。恢复已删除任务，返回恢复后的任务对象。

响应 200

{ "id": 10, "deleted_at": null, ... }
POST/tasks/:id/progress 需登录
添加进展记录（创建者/负责人/管理员可操作）。三个分支三选一。
参数类型说明
statusstring新状态（传递则记录状态变更）
progressinteger进度 0-100（传递则记录进度更新，达 100 自动完成）
commentstring备注说明

响应 200

{ "id": 5, "action": "progress_updated", "progress": 60, ... }

通用说明

鉴权

除 POST /auth/login 与 POST /auth/register 外，所有接口需携带请求头：

Authorization: Bearer <access_token>

错误响应

统一格式（HTTP 状态码对应语义）：

{ "detail": "错误描述" }
状态码含义
400参数不合法
401未认证 / 凭证无效
403无权限
404资源不存在
413请求体超过 MAX_BODY_BYTES
423账号被锁：仅用于存量明文安全答案，需重设安全问题
429频率超限，读 Retry-After 头确定重试时机
500服务器内部错误
503依赖的外部服务不可用（如生产环境未配 SMTP）

操作管理员创建者负责人普通用户

说明

  • 删除为逻辑删除，数据保留，可在回收站恢复；回收站按用户隔离，普通用户只看到自己创建的已删任务。
  • 定时任务：每 30 秒扫描到期提醒并推送；每 10 分钟检查逾期任务生成提醒（每天一条）。
  • 外部通知（Webhook / 邮件）为可选项，未配置则仅站内提醒；推送走异步队列，不阻塞请求，队列满则丢弃并记日志。
  • 限流计数存在进程内存，仅单实例部署有效；多实例扩容需换成共享存储，并记得配置 TRUSTED_PROXIES。
