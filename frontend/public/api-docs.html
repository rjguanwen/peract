API 文档

躬行（Peract）· Go 后端（Gin）· 基础地址 http://localhost:8001/api/v1

系统说明

本系统后端基于 Go + Gin + GORM + SQLite，提供任务登记、分配、进展跟踪、状态查询、提醒、回收站等功能。

  • 除登录/注册外，所有接口均需 Authorization: Bearer <token> 请求头。
  • 登录接口使用 OAuth2 Password 模式（application/x-www-form-urlencoded）。
  • 错误响应统一格式：{"detail": "错误信息"}。
  • 时间字段格式：2026-08-20T18:00:00（本地时间，无时区）。

认证接口

POST/auth/login
用户登录，返回 JWT 访问令牌。请求体为表单格式（非 JSON）。
参数位置类型必填说明
usernameFormstring是用户名
passwordFormstring是密码

响应 200

{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "bearer",
  "user": { "id": 1, "username": "admin", ... }
}
POST/auth/register
注册新用户（角色固定为普通用户）。
参数类型必填说明
usernamestring是2-64 位，字母/数字/下划线/点/横线
emailstring是合法邮箱
passwordstring是至少 6 位
full_namestring否姓名
rolestring否忽略，固定为 user

响应 201

{ "id": 2, "username": "user1", "email": "...", "role": "user", ... }
GET/auth/me 需登录
获取当前登录用户信息。

响应 200

{ "id": 1, "username": "admin", "role": "admin", "is_active": true, ... }

用户接口

GET/users 需登录
获取全部用户列表（用于任务分配选择）。

响应 200

[ { "id": 1, "username": "admin", "role": "admin", ... }, ... ]
POST/users 仅管理员
创建用户。请求体同 /auth/register，但 role 可为 user/admin。

响应 201

{ "id": 3, "username": "zhangsan", "role": "user", ... }
PATCH/users/:id 仅管理员
更新用户（全字段可选，仅传需修改字段）。
参数类型必填说明
full_namestring否姓名
emailstring否邮箱
rolestring否user / admin
passwordstring否新密码（留空不修改）
is_activeboolean否启用/停用

任务接口

POST/tasks 需登录
创建任务（登记）。创建后自动在进展时间线记录「created」。
参数类型必填说明
titlestring是任务标题
descriptionstring否任务描述
prioritystring否low / medium / high / urgent，默认 medium
assignee_idinteger否负责人用户 ID
due_datestring否截止时间 2026-08-20T18:00:00

响应 201

{ "id": 10, "title": "...", "status": "todo", "progress": 0, ... }
GET/tasks 需登录
任务列表，支持组合筛选与分页。
参数位置类型说明
statusQuerystringtodo / in_progress / done
priorityQuerystringlow / medium / high / urgent
assignee_idQueryinteger负责人 ID
keywordQuerystring标题/描述模糊搜索
overdue_onlyQueryboolean只看逾期（true）
mineQueryboolean只看我的任务（true）
pageQueryinteger页码，默认 1
page_sizeQueryinteger每页条数，默认 20，最大 100

响应 200

{
  "items": [ { "id": 10, "status": "todo", ... } ],
  "total": 42,
  "page": 1,
  "page_size": 20
}
GET/tasks/deleted 需登录
回收站：已逻辑删除的任务。管理员可见全部；普通用户仅可见自己创建的任务。
参数位置类型说明
priorityQuerystring按优先级筛选
keywordQuerystring标题/描述模糊搜索
page / page_sizeQueryinteger分页参数
响应结构与 GET /tasks 相同；每条记录包含 deleted_at 删除时间。
GET/tasks/:id 需登录
任务详情，包含完整字段与进展时间线 progresses。

响应 200

{
  "id": 10,
  "title": "...",
  "status": "in_progress",
  "progress": 60,
  "is_overdue": false,
  "progresses": [ { "action": "status_changed", ... } ]
}
PATCH/tasks/:id 需登录
更新任务。权限规则： 编辑基本信息（title / description / priority / assignee_id / due_date）仅限管理员或任务创建者； 状态/进度流转（status / progress）允许负责人操作。
参数类型说明
titlestring标题（仅管理员/创建者）
descriptionstring描述（仅管理员/创建者）
prioritystring优先级（仅管理员/创建者）
assignee_idinteger负责人（仅管理员/创建者）
due_datestring截止时间（仅管理员/创建者）
statusstring状态流转（负责人可操作）
progressinteger进度 0-100，达 100 自动完成（负责人可操作）
状态/进度变更会自动记录到进展时间线，并通知负责人。
DELETE/tasks/:id 需登录
仅管理员或任务创建者。逻辑删除：写入 deleted_at，可在回收站恢复。

响应 204

POST/tasks/:id/restore 需登录
仅管理员或任务创建者。恢复已删除任务，返回恢复后的任务对象。

响应 200

{ "id": 10, "deleted_at": null, ... }
POST/tasks/:id/progress 需登录
添加进展记录（创建者/负责人/管理员可操作）。三个分支三选一。
参数类型说明
statusstring新状态（传递则记录状态变更）
progressinteger进度 0-100（传递则记录进度更新，达 100 自动完成）
commentstring备注说明

响应 200

{ "id": 5, "action": "progress_updated", "progress": 60, ... }

提醒接口

GET/reminders 需登录
当前用户的提醒/通知列表。
参数位置类型说明
unread_onlyQueryboolean只看未读（true）
page / page_sizeQueryinteger分页参数

响应 200

{
  "items": [ { "id": 1, "task_title": "...", "remind_type": "overdue", "read_at": null, ... } ],
  "total": 3, "page": 1, "page_size": 20
}
GET/reminders/unread-count 需登录
未读提醒数量（顶部铃铛角标）。

响应 200

3
POST/reminders 需登录
设置任务提醒（创建者/负责人/管理员可操作）。
参数类型必填说明
task_idinteger是任务 ID
remind_atstring是提醒时间 2026-08-15T10:00:00
messagestring否提醒内容
remind_typestring否manual / overdue / assign / status，默认 manual

响应 201

{ "id": 4, "task_id": 10, "remind_at": "2026-08-15T10:00:00", ... }
POST/reminders/:id/read 需登录
标记提醒为已读（本人或管理员）。

响应 200

{ "id": 4, "read_at": "2026-08-14T14:00:00", ... }

通用说明

鉴权

除 POST /auth/login 与 POST /auth/register 外，所有接口需携带请求头：

Authorization: Bearer <access_token>

错误响应

统一格式（HTTP 状态码对应语义）：

{ "detail": "错误描述" }
状态码含义
400参数不合法
401未认证 / 凭证无效
403无权限
404资源不存在
500服务器内部错误

权限模型

操作管理员创建者负责人普通用户
查看任务✅✅✅✅
创建任务✅✅✅✅
编辑任务信息✅✅❌❌
状态/进度流转✅✅✅❌
添加进展✅✅✅❌
删除任务✅✅❌❌
恢复任务✅✅❌❌
用户管理✅❌❌❌

说明

  • 删除为逻辑删除，数据保留，可在回收站恢复。
  • 定时任务：每 30 秒扫描到期提醒并推送；每 10 分钟检查逾期任务生成提醒（每天一条）。
  • 外部通知（Webhook / 邮件）为可选项，未配置则仅站内提醒。
